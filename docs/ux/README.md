# Camino — UX packet

Hand this folder to a UX / visual designer. Do not start from a habit-tracker or med-reminder template.

| Read first | Why |
| --- | --- |

**Your job:** give the product a visual world and a precise iPhone composition. Lock type, color, scene painting, motion, and iconography.

**Delivered frames:** [`frames/Camino iOS Frames.dc.html`](frames/Camino%20iOS%20Frames.dc.html) (open in a browser). Operate surfaces are in turn 1; warmer scene studies are turn 2.

**Not your job:** change the object model, invent streaks/journals/countdowns, pick Expo, or write code.

**The one custom surface:** the Camino (and Arrival). Everything else should feel like a fluent iOS app — system sheets, lists, pickers, Swift Charts — sitting on that place.
